# The Fellas OS v8 — Visual & UX System

## Direction
Late-night sports network + trophy room.

## Principles
- Data is the hero; decoration supports it.
- Championship gold is reserved for hierarchy, records and active emphasis.
- Each manager has a subtle franchise accent.
- Mobile is treated as the primary group-chat consumption surface.
- Core content remains static HTML and works without JavaScript.
- Search is now embedded client-side and works in local file preview.
- Motion respects `prefers-reduced-motion`.

## Homepage hierarchy
1. League brand + live status
2. Lead story / news ribbon
3. Scorebugs
4. Championship lineage
5. Current command center
6. 2026 scoring pulse
7. Manager portals
8. Weekly archive + analytics labs

## Manager accents
Each current manager page receives a unique accent while preserving the shared Fellas visual system.

## Publishing
Clean folder routes are regenerated from canonical pages using resolved relative links rather than string replacement.
