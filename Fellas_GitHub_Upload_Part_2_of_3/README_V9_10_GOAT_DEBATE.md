# Fellas OS v9.10 — GOAT Debate

Added `analytics/goat-debate.html`, an offline-ready self-contained interactive Mount Rushmore ballot, manager comparison, and championship-only résumé ordering. Homepage entry point added.

Sources: `data/legacy_score_v1.json`, which draws on packaged Hall of Fame title history and `data/league.json` career records. This is explicitly **not** an official all-time ranking. No new scores, gameplay outcomes, or votes were invented. Ballot links use URL parameters, no backend or ballot collection.

Existing site content retained. Historical coverage and other component audits remain open.
