# Free deployment — The Fellas OS

This folder is the **site root**. Upload its **contents**, not a parent folder, into a public GitHub repository (suggested repository name: `fellas-hall-of-fame`).

1. Create a **public** repository on GitHub Free.
2. Upload every file and folder here, including `index.html`, `assets/`, `analytics/`, `data/`, `managers/`, and the empty `.nojekyll` file. You can also use Git from your desktop.
3. In the repository choose **Settings → Pages**. Under Build and deployment, choose **Deploy from a branch**; Branch **main**, folder **/(root)**; Save.
4. The site should appear at `https://YOUR-USERNAME.github.io/fellas-hall-of-fame/` (substitute your username/repository). It may take several minutes to publish.
5. Open in mobile and desktop browsers. Check dashboards, navigation, manager pages, the Trade Museum, Legacy Score, SportsCenter, and Playoff Race.

## Important
- Hosting is free on a **public** GitHub Free repository. The source code and published content are **public**, not password protected. Do not upload personal information, secrets, API keys, private files or sensitive unreviewed material.
- The published snapshot is **2026 through Week 6**, not live. The Week 7–14 schedule is verified; playoff chances are **model estimates**, not provider probabilities.
- The Fellas' **six-team playoff field is confirmed**. The first two byes and tiebreakers remain unconfirmed.
- This is a league feedback preview, not a fully certified all-time history.
- To update later, replace changed source files and commit to main. GitHub Pages will redeploy.


## Confirmed Fellas playoff rules
Six playoff teams qualify; seeds 1 and 2 get first-round byes. The playoff-race page displays top-two probability as first-round-bye probability. Official tiebreakers and regular-season end week are pending confirmation.
